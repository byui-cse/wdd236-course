# Compact investigation record

Offer this structure within the student's existing contract or review notes. Keep it brief; omit irrelevant fields. Unperformed checks remain planned, and the student's own contributions remain distinct from AI proposals.

```text
Feature / user action:
Project version or date (and relevant uncommitted changes):
Competency slices, if applicable:
Question I am investigating:

My initial explanation or prediction:
Support used: guided / shared / independent

Map: responsibility / interaction / state
[Diagram or text sequence]
Source index: map parts and arrows → file + symbol (+ lines when available)
Hypotheses or missing connections:

Pattern and the problem it solves:
Quality claim:
Implementation mechanism supporting it:

Variation challenged:
My prediction before checking:
Check and conditions:
Who ran the check:
Observed result (or “not checked”):
What I corrected in my explanation or map:
Limitation or tradeoff:

Transfer question and my explanation:
What is now supported by source:
What is now supported by observation:
What remains uncertain:
Next step:
```

For peer practice, add the partner's question and what it helped clarify. Do not label this record an official competency pass-off.
