## Topics

- Read [WCAG 2 Overview](https://www.w3.org/WAI/standards-guidelines/wcag/).
- Read [Keyboard Accessible](https://developer.mozilla.org/en-US/docs/Web/Accessibility/Guides/Understanding_WCAG/Keyboard).
- Read [ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/).
- Identify one current UI flow in your project that is likely difficult for keyboard or assistive technology users.

## Submission

- Submit an accessibility findings note with:
- At least three accessibility risks found.
- One prioritized fix you will implement this week.
- A short test plan for verifying the fix.
