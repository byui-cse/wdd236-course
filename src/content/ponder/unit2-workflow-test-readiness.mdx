## Introduction

This practice activity helps you verify that your component is ready to support a real workflow, not just an isolated demo.

Use this as your final design-quality pass before completing the Unit 2 prove.

## **01** Contract and Boundary Check

Start by validating your component contract.

For your primary component, confirm:

1. Inputs are clear:
	- Attributes
	- Properties
2. Outputs are clear:
	- Events and event payloads
3. Slots are documented (if used)

Then define boundaries:

1. In scope for this component
2. Out of scope for this component

If a behavior belongs to page-level workflow orchestration, keep it out of component scope.

## **02** Workflow Integration Check

Pick the critical workflow you will implement and verify:

1. Which steps are handled by the component?
2. Which steps remain page-level logic?
3. Where does data/state enter and leave the component?
4. Which event(s) trigger workflow transitions?

## **03** Test Readiness Check

Review your test plan and confirm coverage for:

1. Normal path behavior
2. Alternate/error path behavior
3. Event contract behavior (correct event names and payload shape)
4. Accessibility behavior (labels, instructions, keyboard flow, or feedback)

If a check has no test idea yet, add one before submitting prove.

## **04** Accessibility and Scope Creep Check

Document at least:

1. One keyboard interaction expectation
2. One screen-reader or labeling expectation
3. One expected error state and how users receive feedback

List one feature you are intentionally not implementing in Unit 2 and explain why.

Then answer:

- Is this feature required for workflow success right now?
- If yes, move it into scope and update your plan.
- If no, keep it out of scope and document it in your decision notes.

## Team Discussion Prompts

1. Where is your largest implementation risk right now?
2. What piece of your component contract is still ambiguous?
3. What would make your prove evidence strongest for a reviewer?
4. Which planned feature is most likely to cause scope creep this week?
