# Unit Authoring Workflow (Reusable)

This is the process used to complete Unit 1 and should be reused for Units 2-6.

## 1) Audit the Unit as a System

Read the unit overview, both Prepare activities, linked Ponder activities, and the Prove assignment.

Create a quick map:

- Prove artifact
- Where it is introduced (Prepare)
- Where it is practiced (Ponder)
- Where it is finalized (Prove)

If any Prove requirement is not scaffolded earlier, add scaffolding.

## 2) Keep a Two-Week Arc

- Week 1: framing and scope
- Week 2: quality and integration
- End of Unit Prove: synthesis + extension

## 3) Prepare Should Teach Before It Asks

Every submission bullet in Prepare should be supported by readings or explicit guidance.

## 4) Ponder Should Rehearse Judgment

Use one Ponder per week:

- Week 1 Ponder: clarify scope, users, and intent.
- Week 2 Ponder: quality checks and coherence across artifacts.

## 5) Prove Should Be More Than Compilation

Prove should require students to:

1. Consolidate draft work from both weeks.
2. Revise weak areas.
3. Expand to a complete, instructor-ready package.

## 6) Rubric Must Match Requirements

If you add requirements (for example, more stories or additional views), update rubric criteria in the same edit.

## 7) Final Validation

- Run `pnpm build`.
- Fix frontmatter, markdown, or route errors.
- Verify links and collection consistency.
